# 会议耳朵

把电脑正在播放的声音（腾讯会议、飞书会议、播放器、网课……）转成文字，静音后整句自动发到当前对话。

## 它做什么

- 通过 Windows WASAPI loopback 录制**默认输出设备**，得到“对方说的话”和系统播放的声音；
- 同时可采集**默认麦克风**，把你自己说的话也转写进来，分别标成 `对方：` / `我：`；
- `我：` 的句子不会单独发送，而是作为上文缓存，随下一句 `对方：` 一起发出（2 分钟内、最多 6 条）；
- 打开「只把对方的问题发给我」后，对方的陈述句也只进上下文；问句由关键词规则判定，打开「用模型判断是不是问题」后改由你选的模型判定（超时或失败自动退回关键词）；
- 语气词（嗯/啊/哦/对/好/是的…）和 15 秒内重复的句子会被直接丢弃；
- 用扬声器时麦克风会听见对方（回声），Host 会按「时间重叠 + 文本相似」把重复的麦克风那句丢掉；
- 本地断句：检测到连续说话 → 等设定的静音时间 → 把这一整句（最多 45 秒）送去识别；
- 使用 DSH 自带的本地 SenseVoice 模型（离线、CPU、中文最好），音频不出本机。
- 当前输入框空闲时，自动把这句话填进去并发送；输入框正在发送或不可用时，先攒着，点“插入”再手动发。

## 怎么用

1. 在插件详情里确认已启用。识别用的是 DSH 自带的语音服务，需要同时启用官方 **语音输入（Voice input）** 插件，提供本地 SenseVoice 模型。
2. 输入框工具行（麦克风按钮旁边）会出现一只“耳朵”按钮。首次点击时若模型没下载，会先下载 SenseVoice（INT8 约 240 MB，走 Hugging Face 或 HF-Mirror），进度显示在下方状态行；就绪后才开始采集。
3. 播一个带人声的视频验证：说完一句话、停顿超过设定的静音窗口，句子的文字会填进输入框并自动发送。
4. 监听期间下方只显示一行：停止按钮、音量条、最近一句、待发送条数。**没有下拉框**。
5. 静音窗口（毫秒）、采集设备、识别语言、是否自动发送，都在**本插件详情页的「监听设置」**里改，保存后写入你的 profile 配置，重启也保留。

## 要求与限制

- 捕获 helper 是 Python 脚本，需要本机有 Python 3.10+，并安装 `pyaudiowpatch` 与 `numpy`（`python -m pip install pyaudiowpatch numpy`）。缺少依赖时这一行会直接显示错误原因。
- 只处理一个输出设备：默认跟随系统，也可以在详情页钉死某个 loopback 端点。播放设备轮换时先在 Windows 里切默认输出。
- WASAPI loopback 在没有程序播放声音时会停住，helper 会持续输出静音流保活，这是正常现象（不会有声音）。
- 识别是“整句离线识别”，不是逐字流式字幕；句子结束后约 1 秒出字。
- 麦克风里的你自己的声音不会被采集；但如果某个会议软件把你自己也回放出来，仍会被转写。
- 耳朵按钮在输入框工具行、麦克风旁边，与官方语音输入按钮共存；官方语音输入插件被禁用时本插件不会激活。
- 时间戳、说话人区分暂不提供；面板只保留最近 40 句用于显示。

## 可调配置（`cordis.patch.yml` 的 `config`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `pythonPath` | `python` | Python 可执行文件；GUI 环境找不到时填绝对路径 |
| `silenceMs` | `1000` | 多久静音算一句话结束（详情页可改，改完写入 profile） |
| `maxUtteranceMs` | `45000` | 单句最长时长，防止一口气说不停 |
| `language` | `zh` | 识别语言：`zh`、`en`、`yue`、`ja`、`ko`、`auto` |
| `autoSend` | `true` | 关掉后逐句追加到输入框、不自动发送（自己按回车） |
| `mic` | `true` | 是否同时采集麦克风（你的声音，标成“我”） |
| `micDevice` | 默认麦克风 | 麦克风名的一部分，钉死采集设备 |
| `device` | 默认输出 | loopback 设备名的一部分 |

模型数据目录由语音服务管理，重复安装或禁用插件都不会重新下载。
